# 数据结构大纲

## 一、线性结构（一对一）

| 数据结构     | 特点                                   | 典型应用                       |
| ------------ | -------------------------------------- | ------------------------------ |
| 数组         | 连续内存，随机访问 O(1)，插入删除 O(n) | 存储固定大小序列、查找表       |
| 链表         | 节点+指针，插入删除 O(1)，访问 O(n)    | 频繁插入删除、实现栈/队列      |
| 栈           | 后进先出（LIFO）                       | 函数调用、括号匹配、表达式求值 |
| 队列         | 先进先出（FIFO）                       | 任务调度、BFS、缓冲区          |
| 双端队列     | 两端都可进出                           | 滑动窗口、撤销操作             |
| 串（字符串） | 字符序列                               | 文本处理、模式匹配             |

## 二、树形结构（一对多）

| 数据结构                 | 特点                            | 典型应用             |
| ------------------------ | ------------------------------- | -------------------- |
| 二叉树                   | 每个节点最多两个子节点          | 基础树结构           |
| 二叉搜索树（BST）        | 左小右大，查找 O(log n)（平均） | 有序数据查找         |
| 平衡二叉树（AVL/红黑树） | 自动保持平衡，查找稳定 O(log n) | map/set 底层         |
| 堆                       | 完全二叉树，大顶/小顶           | 优先队列、堆排序     |
| B树/B+树                 | 多路平衡查找树                  | 数据库索引、文件系统 |
| Trie（字典树）           | 按字符前缀组织                  | 自动补全、拼写检查   |
| 哈夫曼树                 | 带权路径最短                    | 数据压缩编码         |

## 三、图状结构（多对多）

| 数据结构      | 特点               | 典型应用             |
| ------------- | ------------------ | -------------------- |
| 邻接矩阵      | 二维数组表示边     | 稠密图               |
| 邻接表        | 每个顶点挂一个链表 | 稀疏图               |
| 有向图/无向图 | 边是否有方向       | 网络、依赖关系       |
| 带权图        | 边有权值           | 最短路径、最小生成树 |

## 四、散列结构

| 数据结构   | 特点                              | 典型应用                  |
| ---------- | --------------------------------- | ------------------------- |
| 哈希表     | 通过哈希函数 O(1)                 | 平均查找 字典、缓存、去重 |
| 布隆过滤器 | 概率型，判断“可能存在/一定不存在” | 缓存穿透防护、去重        |

## 五、其他常用抽象结构

- 并查集：处理不相交集合的合并与查询，用于连通性问题。

- 跳表：多层链表实现有序查找，Redis 有序集合底层。

- 线段树 / 树状数组：区间查询与更新。

- LRU 缓存：哈希表+双向链表，实现最近最少使用淘汰。
