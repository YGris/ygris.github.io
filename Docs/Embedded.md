# 嵌入式

该文档提供嵌入式开发的基本概念和相关板块导航

## MCU（微控制器）架构总结表

| 芯片板块 | 主要功能                                      |
| -------- | --------------------------------------------- |
| CPU      | 执行指令、运算、调度其他板块                  |
| 存储单元 | SRAM或Flash，存储代码或者数据                 |
| 外设     | GPIO、定时器、串口、I2C、SPI、ADC、DAC、CAN等 |
| 电源     | 分配电压、电源管理与低功耗控制                |
| 时钟树   | 提供时间基准                                  |
| 总线     | 连接各模块的通道                              |
